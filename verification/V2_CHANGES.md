### `test_formats.py` (+212 / −21 lines; 18 → 30 tests, all pass ✅)
Two old tests adapted to D1. 12 new: BFP6 hand example + layout, 4-bit clamp, 32\|8\|5 = MXINT6, BFP6 = 3.46% on C, E4M1 one-NaN, range vs saturated, two's complement, storage per format, `quantize_X` blocking, metrics with Xq, exhaustive W+X, stale checkpoint. Also `test_one_ulp_below_power_of_two` (the v1 bug).

### `run_all.py` (new, 397 lines)
One command: tests → baseline (W) → baseline (W+X) → tables T1–T8 → team scripts (`validate_predictor`, `explore`, `make_figures`) → `RUN_MANIFEST.md`. Options `--fresh`, `--npz` (datasets A–E), `--only <step>`. Writes logs to `results/logs/`. ✅ clean run: exit 0, 8 s.

### `run_baseline.py`
`--mode wx`; output `baseline_<tag>_wx`; prints range / saturated / zeroed / subnormal / clamped-block counts; BFP check now compares `BFP6_g32e8` with MXINT6 and prints the D1 BFP6 next to MXINT6.

### `make_figures.py`
Only the label of the shared MXINT6/BFP6 curve: "MXINT6 / BFP6 (same grid)".
